# AI Coding Assistant resources

A repository of resources that you can use with AI Coding Assistants. Rules files, Custom Agents for Kiro CLI, Agent Hooks and more.

It is a bit of a mess, but its stuff I use daily and find useful. I am sharing with the mindset that they might be useful to others, and that sharing is a way that others can see how folk like me are using AI coding assistants on a daily basis.

As this space slows down (wishful thinking!) then I will better curate this set of resources. Until then, use them as is.

Feel free to use these resources, and submit PRs with your own.

## Additional GitHub repos that container other useful AI agent resources (Skills, Promptes, etc)

**General Development/Coding**

* [clean-code-skills](https://github.com/ertugrul-dmr/clean-code-skills) - This repository contains Agent Skills that enforce Robert C. Martin's Clean Code principles. They work with Google Antigravity, Anthropic's Claude Code, and any agent that supports the Agent Skills standard.

**Web Applications**

* [Web Quality Skills](https://github.com/addyosmani/web-quality-skills) - this is a bunch of Skills which can be adapted to provided detailed analysis/review of your web applictions. SEO, Accessibility, Performence and more. (https://skills.sh/addyosmani/web-quality-skills)

* [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) - an AI-powered reasoning engine that analyzes your project requirements and generates a complete, tailored design system in seconds.

**Data and Database**

[pg-aiguide](https://github.com/timescale/pg-aiguide) - Skill for working with PostgreSQL

[agents](https://github.com/astronomer/agents) - a number of agents/skills that make working with Apache Airflow a joy
